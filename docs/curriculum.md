# Texto para el currículum

## Versión breve

**Helixys — Aplicación de gestión médica | Proyecto personal**  
Python · PySide6 · PostgreSQL · SQLAlchemy

- Desarrollé una aplicación de escritorio para gestionar pacientes, consultas, agenda e historial documental.
- Implementé generación de PDF y Word, junto con módulos de facturación, gastos y rendimientos.
- Integré vistas para médico y asistente, descubrimiento de servidor en red local y dictado por voz con Vosk.

**Repositorio:** https://github.com/HerodeSS14/helixys-portfolio

## Para explicar el proyecto en una entrevista

Helixys reúne el flujo de atención de un consultorio en una aplicación de escritorio. Utilicé PySide6 para la interfaz, SQLAlchemy para relacionar pacientes con sus consultas y documentos, y PostgreSQL para la persistencia. También trabajé en generación documental, audio y conectividad local. La muestra pública incluye capturas con datos ficticios y documentación de las decisiones y limitaciones actuales.

## Cómo presentarlo con precisión

El alcance demostrable de este proyecto es desarrollo de escritorio con Python, interfaz gráfica, persistencia relacional e integraciones. No corresponde presentarlo como una aplicación web de Next.js o Laravel. Tampoco se atribuyen usuarios, ingresos, porcentajes de mejora ni resultados de producción que no se hayan medido.
